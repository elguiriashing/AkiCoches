# AkiSuite icon family

AkiCoches: hot-red (`#FF3047`) AkiPasa-proportion map pin, black (`#111111`) four-point star, white square, 128x128 viewBox and 29px rounded corners. No car motif. Normal and maskable PWA/Apple/PNG assets are generated from the source SVG on every dev and build. Keep AkiBusiness's existing AB monogram unchanged, and match the AkiHQ mark to this geometry with black pin and gold star.

Versioned v2 PNGs are generated into untracked paths to keep the release-source git-clean check intact. The obsolete `src/app/apple-icon.png` metadata route is removed in favour of the `icons.apple` declaration.
